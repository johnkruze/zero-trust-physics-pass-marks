# Zero-Trust Physics: pass marks

Zero-Trust Physics is a physics verifier for Super Intelligence (SI). Most of its models are models of one real thing, compared with measurements of that thing. A pass mark is the line the model has to meet in that comparison, and each one here was posted before the measurements it is held to were opened.

Each file under `marks/` is one model's pass mark:

- `model`: the model's name, as the verifier serves it.
- `pass_mark`: the mark, in the words of the model's own description.
- `sha256`: the SHA-256 of the document that fixes the mark.

A new model's mark is added here before the model is compared with its held-back measurements.

## Checking a mark's date

Every mark here is added through GitHub itself, one mark to a commit, so the commit that adds it is made, dated and signed by GitHub. Open a mark's file and choose **History**: the commit is marked **Verified**, and its date is GitHub's.
